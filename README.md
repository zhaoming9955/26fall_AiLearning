- 每周 35 小时：核心任务 26 小时、算法练习 5 小时、复盘 2 小时、缓冲 2 小时。

- 详细安排见 [14 周路线](docs/ROADMAP.md)。

- 每周复制 [周报模板](weekly/TEMPLATE.md)，命名为 `week01.md`、`week02.md` 等。
