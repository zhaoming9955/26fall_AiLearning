## 时间预算

核心任务 26 小时：Python 类、文件与异常 10h；JSON 实验记录本 10h；终端、虚拟环境和 Git 6h。

另安排算法练习 5 小时、复盘与导师同步 2 小时、缓冲 2 小时，总计 35 小时。

## 执行清单

- [ ] 完成教材类、文件和异常部分；练习函数参数、返回值和字典。
- [ ] 编写实验记录本：添加名称、日期、备注，查询记录并保存为 JSON。
- [ ] 关闭程序重新打开，检查数据能否保留；独立增加一个状态字段。
- [ ] 学习终端路径、虚拟环境、依赖安装；查看差异后提交并上传。

## 算法练习

主题：数组、字符串、字典。前期约 4 道新题加复做，中等题阶段可降至 2—3 道；以能独立实现和解释为准。

## 最低验收

- [ ] 新增、查询、保存记录；用 status/diff/add/commit/push 完成一次上传
- [ ] 在复盘中留下代码路径、运行方式、结果和一个真实问题。
- [ ] 查看本次修改，提交并上传到 GitHub。
